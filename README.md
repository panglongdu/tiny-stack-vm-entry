# Tiny Stack VM

Entry for make.fun's [tiny stack VM](https://make.fun/bounty/tiny-stack-vm-01-run-20261122) bounty. `main.ts` is an exact interpreter for the tiny stack ISA: wrapping 32-bit arithmetic, unsigned division and comparison, every trap with its own exit code, bounded stack, call stack and memory, step and output limits. It answers all 40 instances of a set in one run, writing `/output/<id>/stdout.bin` and `/output/<id>/exit.txt` for each.
